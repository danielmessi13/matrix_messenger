# Matrix Messenger

Cliente de mensageria desktop (macOS, Windows e Linux) feito em Flutter, que se comunica com um homeserver [Matrix](https://matrix.org). A comunicação com o Matrix é implementada em Rust com o [Matrix Rust SDK](https://github.com/matrix-org/matrix-rust-sdk) e exposta ao Dart pelo [Flutter Rust Bridge](https://github.com/fzyzcjy/flutter_rust_bridge).
